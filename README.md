# JSTech Prime

Site público da JSTech Prime para apresentar serviços de TV autorizada, planos, testes quando disponíveis, atendimento e suporte.

## Publicação

O site é estático e pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta raiz. O catálogo e os contatos usam funções públicas do Supabase configuradas no projeto JSTech Prime.

## Privacidade

A página usa `noindex,nofollow` e `robots.txt` bloqueado para evitar indexação direta. O cadastro de novidades exige consentimento e deve ser conectado a um provedor de e-mail autorizado antes de qualquer disparo automático.
